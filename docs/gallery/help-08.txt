# Uninstall

Remove biggz-ai from your system. Deletes ~/.biggz/, removes the biggz-orchestrator agent from opencode.json, and strips the persona from AGENTS.md. gentle-ai data is NOT affected.

## Keys
- ENTER — Start uninstall
- Y — Confirm uninstall
- N — Cancel uninstall
- R — Retry after error
- ESC — Back to main menu
