# Agent Builder

Create custom sub-agent skills with AI: choose a generation engine, describe the agent, optionally attach it to an SDD phase, preview the generated SKILL.md, then install it to your agents.

## Keys
- ↑↓ / j k — Navigate options
- ENTER — Select option
- TAB — Continue from prompt (when text is entered)
- ↑↓ — Scroll SKILL.md preview content
- ESC — Back one step
