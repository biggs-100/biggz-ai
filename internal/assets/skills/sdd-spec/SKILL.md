# SDD Spec

Write structured specifications with requirements and GIVEN/WHEN/THEN scenarios.

## Activation Contract

1. Read proposal to understand scope.
2. Define functional requirements.
3. Write GIVEN/WHEN/THEN scenarios for each requirement.
4. Persist spec artifact.

## Output

- `openspec/specs/{domain}/spec.md`
- Requirements with numbered scenarios
