# SDD Init

Initialize SDD context for a project.

## Activation Contract

1. Detect project language and testing framework.
2. Initialize OpenSpec artifact store.
3. Cache testing capabilities.
4. Set up SDD registry.

## Output

- `openspec/` directory structure
- `openspec/config.yaml` with testing capabilities
- Skill registry index
