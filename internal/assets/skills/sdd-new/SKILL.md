# SDD New

Create a new SDD change from scratch.

## Activation Contract

1. Ask for a brief change description.
2. Create the change directory under `openspec/changes/`.
3. Initialize proposal document.
4. Start the explore or propose phase.

## Output

- `openspec/changes/{change-name}/proposal.md` (draft)
