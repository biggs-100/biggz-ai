# SDD Onboard

Guide a user through their first SDD cycle.

## Activation Contract

1. Verify SDD is initialized.
2. Walk through each phase: explore → propose → spec → design → tasks → apply → verify → archive.
3. Explain the purpose of each phase.
4. Help the user complete their first change.

## Output

- First completed SDD change
- User understands the workflow
