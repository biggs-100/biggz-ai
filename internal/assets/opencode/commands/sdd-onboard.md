# /sdd-onboard

Guided SDD walkthrough — onboard a user through the full SDD cycle using their real codebase.

Launches the hidden `sdd-onboard` sub-agent to guide the user step by step through explore → propose → spec → design → tasks → apply → verify → archive.

**Hard gates**: SDD Session Preflight must be complete before onboarding starts.

**Usage**: `/sdd-onboard`

**Output**: Completed SDD cycle with archived change
