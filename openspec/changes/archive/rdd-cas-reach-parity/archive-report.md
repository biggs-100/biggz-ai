| Decision | Choice | Reason |
|----------|--------|--------|
| **Revision digest domainHash** | `computeGenerationRevision` returns `domainHash(RDDModeOverrideDigestDomain="biggz-ai.rdd-mode-override-digest/v1", writeLengthPrefixed(schema, gen10, prevRev, mode, recordedAt))` reused from `artifact.go` | Matches gentle parity, collision-domain isolation with length-prefix framing vs raw `sha256(json)` |
| **Generation encoding** | `gen-%010d.json` 10-digit zero-padded, `maxGeneration=999999999` guard | Lexicographic order + exhaustion guard, spec exact |
| **LOCK contract reuse** | `WithNamedFileLock(genDir,"LOCK")` `flock` + stale(5m) PID, held across scan→read→CAS→compute→publish | Reuses tested `lock.go` primitive, Unix flock + Windows fallback, avoids duplicate impl |
| **Immutable publish** | `rddPublishImmutable` `O_CREATE\|O_EXCL\|O_WRONLY`, `bytes.Equal` same-bytes idempotent, else `ErrPublishImmutableConflict` | Preserves CAS and repair semantics, prevents silent overwrite |
| **Head discovery split** | `scanGenerationHead` name-only no read + `readLatestGeneration` parse+validate `mode==disabled` + `revision==computeGenerationRevision` | Lets corrupt repair reuse same slot without losing max generation |
| **CAS validation in-LOCK** | `expectedRevision==head.Revision` authoritative inside `SetCloneLocalRDDMode` under LOCK, `VerifyCloneRevision` advisory only, `empty` only if no record → `expected "x" but head is "y"` | Atomic, avoids race pre-check |
| **Corrupt repair same-slot** | On `*RDDModeUnreadableError` reuse `headGen` same `gen-%010d.json` via `WriteFile` truncate (not `O_EXCL`), not chain new slot | Restores chain at same generation, repair overwrites corrupt once |
| **Mirror path ordering relocated first** | `relocated=<commonDir>/biggz/rdd-mode` then `mirror=<commonDir>/gentle-ai/rdd-mode`, `relocated` first to avoid hostage #2882, mirror best-effort `MkdirAll` even when parent missing | Multi-install safety #3284, fresh clone yields `ReachMachine` not `ThisBuild` unless `Mkdir` fails |
| **Reach enum** | `RDDModeReach string` `ReachUnreported=""` `ReachMachine="machine"` `ReachThisBuild="this_build"` | Mirrors `gentle-ai` enum, reads never probe mirror → `""` |
| **Partial apply error** | `RDDModePartialApplyError{RelocatedPath,MirrorPath,Cause}` `Is ErrRDDModePartiallyApplied` only when `relocated ok && mirror reachable but publish fails` | Half-applied never reported as fully applied |
| **RDDDisabledError source typing** | `RDDModeSource` typed `default/global/clone/clone_local/worktree`, `reviewModeEnableForSource` single `biggz rdd enable --scope=global` for default/global vs chained `global then clone` for clone/worktree, `rddOperationSubject` frozen wording only for `mutate` | Exact runnable continuation per source, preserves `errors.Is(ErrRDDDisabled)` sentinel |
